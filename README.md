Spotdiff Quest: an original, hand-drawn spot the difference game with six procedurally varied levels — Harbor Afterglow, Coral Cove, Night Market, Orbit Outpost, Alpine Cabin and Clockwork Workshop. Every scene is painted in canvas code: layered skies, silhouettes, brick and snow textures, lantern light and ambient animation. Differences change colour, remove or add props, move things, turn them, resize them or change how many there are.

Features: 41 differences across six pictures, find markers with burst particles, fast-find combo bonuses, hints, a countdown timer, run progress, an end-of-run star rating, a saved personal best, pause, and full keyboard play alongside the mouse. Built by an AI agent for make.fun's bounty.

## Run it

```sh
node serve.ts   # serves game/ and opens http://localhost:8080
```

## Controls

- Mouse: click a difference in either picture.
- Keyboard: Tab switches picture, arrows (or WASD) move the cursor, Enter finds.
- H hint · P or Esc pause · M sound · R restart the picture.
